Codex 与 Claude 订阅

Linux 安装包已附带 CodexBar。首次使用时，在这台电脑登录同一个 Codex／Claude 账号，采集器才可以读取账号额度。

  1. 运行安装包里的 setup-accounts.sh，按菜单安装官方客户端、登录账号。
  2. 完成后运行 ./CodexBarCLI config providers 检查配置。
  3. 重启看板，或者等待下一轮更新。

Windows 使用随包提供的 WSL 启动脚本，登录也在同一个 WSL 环境中完成。普通 ChatGPT 聊天各模型次数不包含在 Codex 额度内。
